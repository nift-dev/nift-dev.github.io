Scripting · CLI hosts

Run scripts & use the interactive shell.

The same native statement engine powers standalone files with nift run path and the persistent nift sh interpreter.

nift run

nift run scripts/report.nift
name := read()
print("hello, \$[name]")
return 0

A script starts in a fresh root scope. Fallthrough and bare return exit successfully without return output; return expression renders the returned value to stdout. Parse, runtime and I/O errors use stderr and a non-zero status.

nift sh

$ nift sh
/path/to/project:~? x := 10
/path/to/project:~? x++
/path/to/project:~? print(x)
11
/path/to/project:~? cd("/tmp")
/tmp:~?

The shell retains one root lexical environment between commands. Its prompt shows the current working directory; on a colour-capable terminal the path is green and the ~ marker is blue. cd(path) changes both the process working directory and the next prompt.

Ordinary errors are reported without destroying the persistent session. Multiline parser-state hardening remains part of the v4.3 certification work; the shell already supports the implemented native statement host and persistent state.
