Scripting & runtime · bytes

Handle raw bytes as a first-class value.

bytes is an immutable, shared-backed byte value. It is the language's representation for binary data and interoperates with the FFI byte bridges without ever aliasing mutable native storage.

b := bytes([0x48, 0x69])
print(b.size())          // 2
print(b[0])              // 72
print(b.to_hex())        // 4869
print(b.decode("utf-8")) // Hi

Construction

Build bytes from an array of byte integers, from a string (UTF-8 encoded), or from the byte-reading I/O helpers. Invalid byte values and non-byte inputs raise controlled errors rather than producing a malformed value.

from_array := bytes([1, 2, 3])
from_text  := "héllo".encode("utf-8")

Operations

Byte values support indexing and size()/empty(), concatenation with +, slice(), take()/skip(), contains(), equality comparison, to_hex()/from_hex(), and strict UTF-8 decode(). Out-of-range indexing and invalid UTF-8 decode are controlled errors.

Identity and sharing

Bytes are immutable and share their backing storage. Assignment, copy()/deepcopy(), closures, nested aggregates, mutex values, and thread/async transfer all preserve the shared backing while giving each aggregate shell independent identity.

Text and JSON boundaries

Bytes are intentionally not text. Value/text serialization and JSON reject bytes; convert explicitly with decode() or to_hex(). Checked JSON extraction of byte values is available at the embedding boundary.

Byte I/O

open_bytes(path) and the stream/managed-file byte reads return bytes; exact raw byte writes are additive and leave existing text I/O unchanged.

data := open_bytes("./asset.bin")
print(data.size())

FFI bridges

ffi_buffer(bytes) and ffi_snapshot_bytes(buffer) are explicit copying bridges: immutable bytes never alias mutable native storage. ffi_bytes() is unchanged.
