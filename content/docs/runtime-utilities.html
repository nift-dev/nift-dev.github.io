Scripting & runtime · utilities

Time, sleep and secure randomness.

Small native runtime utilities added in v4.6: wall-clock epoch milliseconds, a blocking sleep, an identity-preserving monotonic stopwatch, and operating-system secure random bytes.

Time and sleep

now := epoch()      // Unix epoch milliseconds (integer)
sleep(250)          // blocks this execution thread for 250 ms, returns null

Monotonic stopwatch

timer() is an opaque, identity-preserving monotonic stopwatch with start, pause/resume, stop, reset, elapsed-millisecond, and state operations. Timer handles are Parser-local and are rejected at rendering, embedding, serialization, and thread/future transfer boundaries.

t := timer()
t.start()
sleep(10)
print(t.elapsed())  // elapsed milliseconds

Secure random bytes

secure_random_bytes(n) returns up to 10,000,000 bytes from the operating-system CSPRNG, with no fallback pseudorandom generator.

token := secure_random_bytes(32).to_hex()

Output streams

Runtime output uses execution-scoped stdout and stderr sinks. err(value) writes one atomic line to stderr with the same value rules as print(value), and embedding captures both channels separately from values, diagnostics, and rendered content.
