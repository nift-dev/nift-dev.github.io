Scripting · File streams

File streams.

Use open(path) for convenient whole-file text, file(path) for managed transactional editing, and ifstream(path)/ofstream(path) when data should be consumed or produced incrementally.

Input streams

stream := ifstream("data.txt")

line := stream.read_line()
rest := stream.read_all()

close(stream)
MethodResult
read(n)Read up to n bytes from the current position.
read_line()Read the next line.
read_all()Read the remaining stream contents.
read_val()Parse the next serialized Nift data value using Nift's value parser.
write_val(value)Serialize any value as compact JSON followed by a newline (JSON Lines), enabling round-trips with read_val().
eof()Report the stream's EOF state.
values := ifstream("values.txt")
flag := values.read_val()
count := values.read_val()
items := values.read_val()

read_val() reads exactly one value from the current stream position, skipping leading whitespace, and leaves the position immediately after that value (trailing whitespace is not consumed). It understands supported serialized Nift data values: null, true/false, integers, floating-point numbers, quoted strings, JSON arrays and JSON objects, including nested structures. At end of stream it returns null. Repeated calls consume sequential values where the input separates them (for example JSON Lines or any whitespace-separated series). Malformed input is a hard error — read_val() reports cannot parse value rather than silently becoming a string. It is only valid on input streams.

Output streams

out := ofstream("result.txt")
out.write("hello")
out.write_line(" world")
out.write_val({"count": 3, "ok": true})
out.flush()
close(out)

ofstream(path) creates/truncates its output file. Streams are resource values with identity and closed-state checks; they are not directly renderable as template/console values.

write(value) writes a renderable scalar (strings and numbers) without quotes; write_line(value) appends a newline. To serialize structured data use write_val(value), which writes any value — scalar, array or object — as compact JSON followed by a newline. A write_val()/read_val() pair round-trips values through a file:

out := ofstream("data.jsonl")
out.write_val({"name": "nift", "tags": ["build", "static"]})
out.write_val([1, 2, 3])
close(out)

in := ifstream("data.jsonl")
first := in.read_val()
second := in.read_val()
print(first.name)
\@// nift
print(first.tags[0])
\@// build
print(second.size())
\@// 3
close(in)
