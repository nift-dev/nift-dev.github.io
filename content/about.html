What is Nift?

A modern, multi-purpose developer tool.

Nift combines a dependency-aware website build system, expressive templating, a native scripting language and an interactive shell. It is designed to stay small enough to understand while still being useful for serious projects.

Use it as the build layer for a site, the frontend generator for an application, a scripting runtime for automation, a data transformation tool, or the glue between the tools you already use. Nift does not need to own your whole stack to be useful.

What can you do with Nift?

A toolkit for real projects.

Nift can be the main build tool for a project or one focused piece of a larger stack.

Websites and documentation

Build fast, modern sites for personal projects, documentation, blogs, product sites and large content-heavy platforms. Templates, partials, tracked outputs and dependency-aware rebuilding keep repeated structure under control.

Learn more →

Frontends for any backend

Use Nift to generate the frontend for APIs and applications written in Go, Node, Python, PHP, serverless runtimes or anything else. Keep runtime concerns in the runtime and let Nift own the files it is good at building.

See examples →

Scripting and automation

Run .f scripts with nift run. Work with files, directories, streams, HTTP requests, JSON and collections; write reusable functions and packages; and automate the repetitive parts of a project without reaching for another language.

Read the docs →

The Nift shell

Use nift sh as an interactive REPL for the same language. Explore data, test expressions, call functions, inspect files and prototype a script one command at a time before saving it.

Get started →
$ nift sh

Data processing

Load, transform, validate and generate structured data. Nift has first-class JSON, arrays, maps, sets, collection operations, schemas and content metadata, making it useful for data-driven pages as well as standalone scripts.

See data features →

Game development

Nift is useful around browser games and interactive projects: generate pages, levels, content, configuration and assets, write build-time or local tooling, and pair it with JavaScript, Canvas, WebGL or another runtime for rendering and input.

Explore →

Developer tools and local apps

Use the scripting language and shell to build project utilities, generators, local workflows and developer-facing tools. Nift can also generate the HTML, data and assets used by desktop or embedded web interfaces.

Learn more →

Built for AI agents

Nift is deliberately legible to both humans and coding agents: plain files, deterministic builds, a consistent scripting surface and explicit project structure. nift init --handover can scaffold a project handover so an agent can understand how the project is meant to be changed.

For AI agents →

Extensible and composable

Import scripts, build reusable packages and compose Nift with the rest of your toolchain. Your bundler, backend, database, image pipeline and deployment platform can keep doing the jobs they already do well.
