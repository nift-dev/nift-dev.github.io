What is Nift?

A modern, multi-purpose developer tool.

Nift combines a dependency-aware website build system, expressive templating, a native scripting language and an interactive shell. It is designed to stay small enough to understand while still being useful for serious projects.

Use it as the build layer for a site, the frontend generator for an application, a scripting runtime for automation, a data transformation tool, or the glue between the tools you already use. Nift does not need to own your whole stack to be useful.

What can you do with Nift?

A toolkit for real projects.

Nift can be the main build tool for a project or one focused piece of a larger stack.

Websites and documentation

Build sites, blogs, documentation and content-heavy platforms. Templates, partials, tracked outputs and dependency-aware rebuilding keep shared structure consistent as your project grows.

Learn more →

Frontends for any backend

Build the frontend for Go, Node, Python, PHP, serverless APIs or any other backend. Keep runtime logic in your existing stack; let Nift generate the pages and files around it.

See examples →

Scripting and automation

Run .f scripts with nift run. Work with files, streams, HTTP requests, JSON and collections. Reuse functions and packages to automate the repetitive parts of a project.

Read the docs →

The Nift shell

Use nift sh to explore the same language interactively. Test expressions, call functions, inspect files and prototype a workflow one command at a time before saving it as a script.

Get started →
